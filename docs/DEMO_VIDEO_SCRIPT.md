# SkillSwap demonstration plan — about 6–8 minutes

| Suggested time | What the video should show |
|---|---|
| 0:00–0:40 | Title, 3 objectives, team, technologies |
| 0:40–1:20 | On Ubuntu, show `docker compose --env-file .env.production -f compose.production.yaml ps` and the Rails and MySQL containers. Open the Windows browser through the SSH tunnel described in the [README](../README.md). |
| 1:20–2:10 | Student login, onboarding, dashboard |
| 2:10–3:10 | Add skill, explore/search, explain mutual vs partial algorithm |
| 3:10–4:20 | Two student accounts: send, receive, accept an exchange request |
| 4:20–5:20 | Schedule a session; demonstrate validation and notification |
| 5:20–6:10 | Complete an ended demo session, submit a review, and show it on the recipient's My Profile page |
| 6:10–7:00 | Admin overview, users, skill categories, monitoring, reports |
| 7:00–8:00 | Show GitHub code, API JSON response, persisted MySQL data, brief wrap-up |

For the complete session flow, seed a past session or use a controlled test clock in your test environment. Never change production timestamps just to fake completion.
