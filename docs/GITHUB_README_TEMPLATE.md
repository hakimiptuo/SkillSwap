# GitHub Project Article Checklist

Recommended README sections:
1. Project introduction and student problem statement.
2. Week 09 title and 3 objectives.
3. Lecturer requirements and how SkillSwap meets each one.
4. UI screenshots from running application (not just Figma).
5. Ruby on Rails MVC architecture and REST API JSON examples.
6. MySQL ERD and tables: users, categories, skills, user_skills, exchanges, learning_sessions, reviews, notifications.
7. Rule-based mutual vs partial matching explanation.
8. Local Docker setup and Ubuntu Server deployment instructions.
9. Group members, ownership, contributions and development process.
10. Test evidence, known limitations and future improvements.
11. YouTube video demonstration link (add once uploaded).

Do not commit `.env`, passwords, tokens, real student data or real meeting links.
