# Week 09 Proposal — SkillSwap

**Project Title:** SkillSwap: A Web-Based Peer-to-Peer Skill Exchange Platform for University Students

**Objective 1:** To develop an interactive web application that enables university students to offer, discover and exchange skills without monetary payment.

**Objective 2:** To implement a rule-based skill-matching mechanism that identifies potential exchange partners based on the skills students offer and want to learn.

**Objective 3:** To develop and deploy an MVC-based web application using Ruby on Rails, MySQL, JavaScript and JSON REST APIs in Docker containers on an Ubuntu Linux server.

**System workflow:** Register → Onboard → Manage Skills → Explore / Match → Request → Accept → Schedule → Complete → Review.

**Technology:** Ruby on Rails 8.1 (MVC), MySQL 8.4, HTML/CSS/JavaScript, JSON API, Docker Compose, Ubuntu Server.
